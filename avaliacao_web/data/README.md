# Dados locais da aplicação

Esta pasta é criada e preenchida durante o uso do sistema. Ela pode conter:

- banco SQLite `corretor.db`;
- avaliações e gabaritos;
- imagens originais e processadas;
- PDFs e pacotes OMR;
- dados de alunos e resultados.

Por segurança, o conteúdo desta pasta não deve ser enviado ao GitHub. O
`.gitignore` mantém apenas este arquivo e o `.gitkeep` versionados.

Faça backups periódicos da pasta inteira.
