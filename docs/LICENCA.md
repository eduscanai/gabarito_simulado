# Escolha de licença

Este pacote não define automaticamente uma licença para o seu código. Sem uma
licença explícita, terceiros não recebem permissão ampla para copiar, modificar
ou redistribuir o projeto.

Antes de tornar o repositório público, escolha conscientemente uma opção, por
exemplo:

- **MIT**: permissiva e simples;
- **Apache-2.0**: permissiva com cláusulas de patentes;
- **GPL-3.0**: exige que derivados distribuídos permaneçam sob a GPL;
- repositório privado sem licença de redistribuição.

A escolha também deve considerar as licenças das dependências, especialmente o
OMRChecker. Não foi inserido um arquivo `LICENSE` para evitar escolher em seu
nome.
